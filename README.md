# Mayank // Powerverse V3

A fully rebuilt, NDA-safe interactive portfolio.

## Tech
- Next.js
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React

## Features
- Cinematic loading sequence
- Editorial hero layout
- Conceptual Power Platform world
- NDA-safe project presentation
- Fictional workflow animation
- Fictional AI invoice extraction demo
- Anime Mode easter egg
- Automation Defender mini-game
- Mobile-first responsive layout
- Resume download
- LinkedIn + email CTA

## Run locally
```bash
npm install
npm run dev
```

## Replace your existing live site
Copy this project's files over your existing repository folder, then:

```bash
git add .
git commit -m "Launch Powerverse V3"
git push
```

Vercel will redeploy automatically.
